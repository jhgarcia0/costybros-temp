# Costy Bros

Página temporária de costybros.com, publicada no GitHub Pages.

## Publicação

O GitHub Pages publica a raiz da branch `main`. Edite `index.html` e faça push para atualizar o site. O arquivo `CNAME` mantém o domínio personalizado.

## DNS

No provedor do domínio, substitua os registros A de `@` por:

- 185.199.108.153
- 185.199.109.153
- 185.199.110.153
- 185.199.111.153

Configure `www` como CNAME para `jhgarcia0.github.io`.
Preserve registros de email e outros serviços. Depois da propagação e emissão do certificado, ative Enforce HTTPS nas configurações de Pages.
